# 高中信息技术实践测试

## 选题

在朋友聚会时，派对音乐的选择是一个常见的问题。在选择时，朋友们之间经常会出现分歧，我们缺少一款可以让大家共同选择曲目，并客观排序的软件工具。在本次测试中，我们决定通过nodejs和vue，使用前后端分离架构设计并完成一款聚会音乐播放器。

## 需求调查

我们在问卷星中设计了一个[问卷](https://v.wjx.cn/vm/tQGgGfb.aspx#)，并在网络上发布，根据问卷结果对软件的功能和算法进行设计。

## 目标

经过多轮迭代和实际测试，完成一款适用于聚会场景的音乐播放器，可以由聚会组织者创建“房间”、生成房间邀请码和密钥口令，访客通过以上信息进入房间，在限制数量内添加自己想听的歌曲，并对列表中的曲目点赞或点踩，列表顺序按照几个不同权重的因素动态变化。播放过程中可以根据问卷中的三个模式（任何人都可以切歌/一半以上的人想切歌才能切歌/所有人都想切歌才能切割）进行切歌，且组织者对播放器拥有完全权限。



在实现了基本的播放功能后，还可以加入网易云音乐账号登录功能，让大家可以登录自己的账号，从收藏夹中的音乐快速选择。组织者也可以登录自己的会员账号实现会员歌曲的播放。

## 步骤

1. 收集问卷结果，确定软件的默认设置和自动排序权重
2. 由人类根据目标和问卷结果自行完成基础的软件架构设计
3. 使用AI Agent独立完成第二条的架构设计
4. 从方案完整性、完成效率、内容质量三个维度，将两份架构进行对比
5. 综合两份架构，制作最终的软件架构，并交由AI Agent完成初版软件的制作
6. 由人类对项目进行验收，并进行多轮迭代
7. 初步开发完成后，在小组内试用该软件，验证其实际效果

## 工具

在本项目中，使用到的AI Agent为Claude Code Desktop和deepseek HARNESS两款。模型则包括deepseek-v4.1-flash、claude-opus-5-5、gpt-6.1-sol。

## 对比

| 维度       | AI Agent                                                     | 人类                                                         |
| ---------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 方案完整性 | 有详细的数据模型和数据库表结构，作为架构设计，结构更为完整与规范，可以作为“蓝图”直接施工，但内容很长，人工审查成本高。 | 功能要求更为清晰和明确，更符合需求，但只能算功能需求清单，不是狭义的软件架构文档 |
| 完成效率   | 高，在提供材料后，仅花费约25分钟                             | 较低，花费时长大于一小时                                     |
| 内容质量   | 较高，考虑到了很多边界情况                                   | 偏低，但产品需求明确                                         |
